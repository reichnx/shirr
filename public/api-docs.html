API Architecture
Main API Facebook Graph API
Uses Facebook's official Graph API with token extraction. Requires valid Facebook cookie.
📊 Handles 50% of shares (max 500 per campaign)
Vern API External Fast API
Uses external Vern API for faster processing. More stable and bypasses rate limits.
📊 Handles 50% of shares (max 500 per campaign)
Parallel Processing
Both APIs run simultaneously using Promise.all() for maximum speed
⚡ Total speed: 20 shares per 2 seconds (10 from each API)

Rate Limits

Share Rate: 20 shares per 2 seconds (10 Main API + 10 Vern API)

Max per Campaign: 1000 shares total (500 Main + 500 Vern)

API Rate Limit: 10,000 requests per minute

Concurrent Campaigns: Unlimited (queued processing)

How It Works
  1. User submits cookie, link, and share amount (1-1000)
  2. System automatically splits amount: 50% to Main API, 50% to Vern API
  3. Both APIs run simultaneously in parallel
  4. Main API extracts token and uses Facebook Graph API
  5. Vern API uses external fast API endpoint
  6. Results are combined into single success/failed counts
  7. Progress shows combined percentage from both APIs
