API Reference

REST API endpoints for Facebook Share Booster

Base URL: http://localhost:5000/api/

Share Operations
POST/share
Start a new share campaign
cookiestring required
linkstring required
limitinteger required (max: 1000)
{ "cookie": "c_user=123; xs=abc", "link": "https://facebook.com/post", "limit": 100 }
GET/share/:id/progress
Monitor campaign progress
GET /api/share/1706123456789/progress
POST/share/:id/cancel
Cancel active campaign
POST /api/share/1706123456789/cancel
Data & Stats
GET/history?limit=20
View share history
GET /api/history?limit=20
GET/stats
Get system statistics
GET /api/stats
GET/running-shares
List active campaigns
GET /api/running-shares
GET/health
Health check endpoint
GET /api/health
GET/tiktok-video
Fetch random TikTok video
GET /api/tiktok-video
Error Codes
400Bad Request - Invalid parameters
404Not Found - Campaign not found
429Too Many Requests - Slow down
500Internal Server Error
