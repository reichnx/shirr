API Reference

Complete REST API documentation for Facebook Share Booster

Base URL: http://localhost:5000/api/

API Information
Primary API: SHIR API (https://shir-api.onrender.com)
Fallback API: Vern API (auto-switch after 2 failures)
Max Shares: 1,000 per campaign
Share Operations
POST/share
Start a new share campaign. Automatically switches to fallback API if primary fails.
cookiestring required
linkstring required
limitinteger required (max: 1000)
{ "cookie": "c_user=123456789; xs=abcdef123", "link": "https://www.facebook.com/post/123", "limit": 100 }
Response: { "status": "processing", "share_id": "1706123456789" }
GET/share/:id/progress
Get real-time progress of a share campaign.
GET /api/share/1706123456789/progress
Response: { "status": true, "share": { "progress": 45, "success": 45, "failed": 0, "status": "processing" } }
POST/share/:id/cancel
Cancel an active share campaign.
POST /api/share/1706123456789/cancel
Data & Statistics
GET/history
View share campaign history.
limitinteger optional (default: 50)
GET /api/history?limit=20
GET/stats
Get overall system statistics.
GET /api/stats
Response: { "total_shares": 1250, "total_successful_shares": 1180, "success_rate": 94, "active_shares": 2, "max_limit": 1000, "primary_api": "https://shir-api.onrender.com/api/shirr", "fallback_api": "https://vern-rest-api.vercel.app/api/share" }
GET/running-shares
List all currently active share campaigns.
GET /api/running-shares
GET/health
Health check endpoint for monitoring.
GET /api/health
GET/tiktok-video
Fetch random TikTok video for dashboard feed.
GET /api/tiktok-video
Error Codes
400Bad Request - Missing or invalid parameters
404Not Found - Campaign or resource not found
429Too Many Requests - Rate limit exceeded
500Internal Server Error - Something went wrong
