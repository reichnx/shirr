API Documentation

Complete reference for Facebook Share Bot API endpoints

Rate: 5 shares per 2 seconds | Max: 5000 shares per campaign

Share Operations

POST /api/share
Start a new share campaign. Shares at 5 requests per 2 seconds.
ParameterTypeRequiredDescription
cookiestringRequiredFacebook cookie for authentication
linkstringRequiredFacebook post URL to share
limitintegerRequiredNumber of shares (1-5000)
// Example Request fetch('/api/share', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ cookie: 'your_facebook_cookie', link: 'https://www.facebook.com/post/123', limit: 100 }) })
// Response { "status": "processing", "message": "Starting share process...", "share_id": "1706123456789" }
GET /api/share/:id/progress
Get real-time progress of a share campaign.
// Example Request fetch('/api/share/1706123456789/progress') // Response { "status": true, "share": { "id": "1706123456789", "progress": 45, "success": 45, "failed": 0, "requested": 100, "status": "processing", "active": true } }
POST /api/share/:id/cancel
Cancel an ongoing share campaign.
// Example Request fetch('/api/share/1706123456789/cancel', { method: 'POST' }) // Response { "status": true, "message": "Share cancelled successfully" }

Data & Statistics

GET /api/history
Get share campaign history.
// Example Request fetch('/api/history?limit=20') // Response { "status": true, "history": [ { "id": "1706123456789", "link": "https://www.facebook.com/...", "success": 95, "failed": 5, "status": "completed", "startTime": "2024-01-25T10:00:00Z" } ] }
GET /api/stats
Get overall statistics.
// Response { "status": true, "stats": { "total_shares": 1250, "total_successful_shares": 1180, "total_failed_shares": 70, "completed_shares": 25, "success_rate": 94, "active_shares": 2, "rate": "5 shares per 2 seconds" } }
GET /api/running-shares
Get currently active/running share campaigns.

System

GET /api/health
Health check endpoint.
// Response { "status": true, "message": "Server is running", "timestamp": "2024-01-25T10:00:00Z", "uptime": 3600, "active_shares": 2 }
