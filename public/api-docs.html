API Reference

REST API endpoints for Facebook Share Booster

Share Operations
POST/api/share
Start a new share campaign
cookiestring required
linkstring required
limitinteger required
{
"cookie": "c_user=...; xs=...",
"link": "https://facebook.com/post",
"limit": 100
}
GET/api/share/:id/progress
Monitor campaign progress
Response: { "progress": 45, "success": 45, "status": "processing" }
POST/api/share/:id/cancel
Cancel active campaign
Data & Stats
GET/api/history
View share history (limit: 20)
GET/api/stats
Get system statistics
Response: { "total_shares": 1250, "success_rate": 94 }
GET/api/running-shares
List active campaigns
GET/api/health
Health check endpoint
Error Codes
400Bad Request - Invalid parameters
404Not Found - Campaign not found
429Too Many Requests - Slow down
500Internal Server Error
