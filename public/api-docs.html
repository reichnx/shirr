FBS API

Smart Dual API - 2 APIs Working Together as One

Base URL: http://localhost:5000/api/

What is FBS API?
FBS API stands for Facebook Share Booster API. It combines TWO powerful APIs into ONE unified system:
Main API (Facebook Graph) Vern API (External Fast API)
Both APIs work together simultaneously. If one API cannot reach its target, the other API automatically takes over to complete the remaining shares. This ensures 100% of your target is always achieved.
Smart Features
Auto Load Balancing Auto Failover Dynamic Target Adjustment Self-Healing
  • Auto Load Balancing: Shares are automatically split 50/50 between both APIs
  • Auto Failover: If one API fails (5+ errors), its remaining shares transfer to the working API
  • Dynamic Target Adjustment: Targets are recalculated in real-time based on API performance
  • Self-Healing: The system automatically recovers from API failures

How FBS API Works
  1. Step 1: User submits cookie, link, and target amount (max 1000)
  2. Step 2: FBS API automatically splits target: 50% to Main API, 50% to Vern API
  3. Step 3: Both APIs start sharing simultaneously in parallel
  4. Step 4: If an API fails (5+ errors), its remaining shares transfer to the working API
  5. Step 5: The working API continues until the FULL target is achieved
  6. Step 6: Results are combined into a single success/failed count
Example Scenario
Target: 100 shares
📊 Initial Split: Main API = 50 shares | Vern API = 50 shares
⚡ Both APIs run simultaneously
❌ Main API fails after 30 shares (5+ errors detected)
🔄 Auto Failover: Remaining 20 shares from Main → Vern API
✅ Vern API continues: Completes 50 + 20 = 70 shares
🎯 Final Result: 100/100 shares completed! (30 from Main + 70 from Vern)
