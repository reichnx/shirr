API Reference

Dual API support for Facebook sharing automation

Base URL: http://localhost:5000/api/

Share Operations
POST/share
Start a new share campaign with API selection
cookiestring required
linkstring required
limitinteger required (1-1000)
use_vernboolean optional (default: false)
{ "cookie": "c_user=123; xs=abc", "link": "https://facebook.com/post", "limit": 100, "use_vern": true }
GET/share/:id/progress
Monitor campaign progress
GET /api/share/1706123456789/progress
POST/share/:id/cancel
Cancel active campaign
POST /api/share/1706123456789/cancel

Available APIs
Main API Facebook Graph API
Uses Facebook's official Graph API with token extraction. Requires valid Facebook cookie.
API External Fast API
Uses external Vern API for faster processing. More stable and bypasses rate limits.
