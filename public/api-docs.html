API REFERENCE

Complete documentation for CyberShare REST API endpoints

SHARE OPERATIONS

POST /api/share
Execute a new share campaign
ParameterTypeRequiredDescription
cookiestringRequiredFacebook authentication cookie
linkstringRequiredFacebook post URL to share
limitintegerRequiredNumber of shares (1-5000)
{
  "cookie": "c_user=123456; xs=abcdef",
  "link": "https://www.facebook.com/post/123",
  "limit": 100
}
GET /api/share/:id/progress
Monitor campaign progress in real-time
Response: { "status": true, "share": { "progress": 45, "success": 45, "failed": 0, "status": "processing" } }
POST /api/share/:id/cancel
Terminate an active campaign

DATA & STATISTICS

GET /api/history
View share campaign history
GET /api/stats
Get overall system statistics
GET /api/running-shares
List all active campaigns
GET /api/health
System health check
